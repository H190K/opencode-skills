# SEO Optimizer

Optimize for search by serving the user intent better than competing pages. Balance crawlability, technical quality, information gain, credibility, and conversion.

## Execution Workflow

1. Identify the page type, audience, business goal, primary intent, and target query set.
2. Check technical basics: indexability, canonical, robots, sitemap, metadata, headings, internal links, structured data, mobile layout, and Core Web Vitals.
3. Improve content around search intent: answer the core question early, add useful depth, remove filler, and include evidence or examples.
4. Add metadata and schema that accurately represent the page.
5. Provide a prioritized action list when doing an audit.

## Quality Bar

Push SEO work beyond keyword insertion:
- Match search intent before optimizing wording.
- Make title tags click-worthy and accurate.
- Keep meta descriptions useful, specific, and non-spammy.
- Use one clear H1 and a logical heading hierarchy.
- Add internal links that help users continue the task.
- Use descriptive alt text for meaningful images.
- Avoid duplicate, thin, outdated, or cannibalizing content.
- Improve E-E-A-T with author signals, citations, examples, product proof, reviews, or original data where relevant.
- Treat Core Web Vitals and mobile usability as ranking and conversion issues.

## Technical Checks

Verify:
- Page is indexable when it should be.
- Canonical points to the preferred URL.
- Title is unique and usually under 60 characters.
- Meta description is unique and usually 140-160 characters.
- Open Graph/Twitter tags match page purpose when sharing matters.
- JSON-LD schema is valid and not misleading.
- Images have dimensions, compression, and lazy loading where appropriate.
- Links are crawlable and important pages are not orphaned.

## Content Strategy

For new or revised content, define:
- Primary query and intent.
- Secondary questions and related entities.
- Content angle and information gain.
- Suggested title, H1, slug, meta description, and outline.
- Internal links in and out.
- Conversion path or next action.
- Measurement plan: impressions, CTR, ranking, organic conversions, engagement, and index coverage.

## Finish Checklist

Verify the final recommendation is prioritized by likely impact, implementation effort, and confidence. Avoid promising rankings; give evidence-based improvements and measurable next steps.
