# Playwright Cleanup

Removes cached browser binaries, temporary browser profiles, and any screenshots or logs generated by Playwright or Playwright MCP.

## Usage

Run this skill to clean up Playwright artifacts:

```bash
opencode run skill playwright-cleanup
```

Or run the script directly:

```bash
~/.config/opencode/skills/playwright-cleanup/cleanup.sh
```

## What It Cleans

1. **Browser binaries** at `~/Library/Caches/ms-playwright/` (Chromium, ffmpeg, etc. — typically ~500 MB).
2. **MCP browser profiles** at `~/Library/Caches/ms-playwright-mcp/` (ephemeral session data).
3. **Any screenshots** (`page-*.png`, `page-*.jpeg`) in `~/Desktop`, `~/Downloads`, `/tmp`, and `/var/tmp`.
4. **Any Playwright-related temp files** in `/tmp` and `/var/tmp`.

## Notes

- Browser binaries will be re-downloaded automatically the next time Playwright or Playwright MCP runs.
- Screenshots and logs are only saved if you explicitly passed a `filename` parameter — this skill finds and removes any that exist.
- Run `du -sh ~/Library/Caches/ms-playwright/` before and after to see space reclaimed.

## Restoring

There is no backup — Playwright will re-download binaries on next use. If you need Playwright immediately after cleanup, the first run will take a moment to download browsers.
